# A tua música

Põe aqui os teus ficheiros (mp3, m4a, ogg) e escreve-os em `tracks.json`:

```json
[
  { "file": "faixa-1.mp3", "title": "Nome da faixa", "artist": "Artista" }
]
```

Com a lista vazia (`[]`) a barra de música não aparece no ecrã de treino.
Os nomes dos ficheiros são teus. Só o que tens legitimamente para tocar.
